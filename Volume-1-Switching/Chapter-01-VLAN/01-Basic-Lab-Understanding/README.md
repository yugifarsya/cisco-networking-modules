# Lab 01: Basic VLAN Configuration

## Objective
- Create and name VLANs on a Cisco Catalyst switch.
- Assign access ports to respective VLANs.
- Verify network isolation between different broadcast domains.

## Topology Overview
- Switch: Cisco 2960
- VLAN 10: Ruang1 (192.168.10.1/24-192.168.10.2/24)
- VLAN 20: Ruang2 (192.168.10.3/24-192.168.10.4/24)
